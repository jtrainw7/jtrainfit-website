How to Set Up Claude Projects
Step by step
// WHY THIS MATTERS

Without Projects, every new conversation with JT starts from zero. With Projects, JT already knows your goals, your context, your voice, and your constraints the moment you open a chat. It's the difference between briefing a new contractor every time vs. working with a dedicated team member who never forgets.

01
Open Claude.ai on Desktop
Go to claude.ai. In the left sidebar, look for "Projects" — it's below your recent chats. Click it to open the Projects area.
02
Create a New Project
Click "New Project". Name it exactly as listed — e.g. Iron Oath Brotherhood. Give it a one-line description so you can identify it fast.
03
Add the Project Instructions
Inside the Project, find "Project Instructions" or "Custom Instructions." This is the system prompt — it tells JT exactly who you are, what this project is, and how to operate inside it. Go to Tab 3 and copy the config for each Project. Paste it here.
04
Upload Relevant Files
Each Project can hold files JT references in every conversation. Upload things like: Iron Oath OS doc, Brotherhood blueprint, your current programming, FCA donor list context, content pillars doc. JT will use these automatically.
05
Start All Sessions Inside the Project
This is the key habit: always open new chats from inside the Project, not from the home screen. Home screen chats don't get Project context. Project chats get everything.
06
Repeat for All 5 Projects
Create all 5 projects in one sitting. Takes about 20 minutes total. Once done, your entire JT operating system is live and persistent — every session from here on starts fully loaded.
07
Update Monthly
When your goals, context, or priorities shift — edit the Project Instructions to reflect it. Takes 2 minutes. Keeps JT operating on current intel instead of outdated context.
